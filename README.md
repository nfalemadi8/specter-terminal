# SPECTER Terminal

Bloomberg-style financial dashboard with 33+ modules covering stocks, crypto, ETFs, bonds, commodities, options, forex, and Islamic finance.

**Live:** [nfalemadi8.github.io/specter-terminal](https://nfalemadi8.github.io/specter-terminal)

## Tech Stack

React 18 · Vite · Tailwind CSS · Recharts · JetBrains Mono · localStorage persistence

## Features

- 33+ lazy-loaded financial modules with code-split architecture
- Bloomberg-inspired dark terminal aesthetic with custom bb- design system
- Options pricing with Black-Scholes, stress testing with 10 historical scenarios
- GCC/Islamic finance: Shariah screening, Sukuk, Saudi Aramco, Emaar
- Portfolio management with CSV export, alerts, and multi-currency support (QAR, AED, SAR, USD, EUR, GBP, JPY, CHF, AUD)
- M&A deal tracker, billionaire tracker, AI insights, backtest engine
- Command palette (Ctrl+K) with keyboard navigation

## Setup

```bash
npm install
npm run dev
```

## Note

All market data is simulated for demonstration purposes.
